# 제품 설계 문서

product-planner가 쓰고 운영자가 GO 하는 신규 기능·모드 설계 문서 폴더. 파일명 `YYYY-MM-<slug>.md`.
승인되면 **큰 기능·신규 모드**는 쪼갠 목록을 BACKLOG에 넣지 않고 기능 세션(`/feature <기능>`)이 이 문서를 직접 읽어 feature 브랜치에서 소화한다. **크기 중간 이하의 화면·기능 개선**은 쪼갠 항목을 [../BACKLOG.md](../BACKLOG.md) "다음" 표에 넣고 ops 사이클이 소화한다(예: [2026-10-lobby-settings-ux.md](2026-10-lobby-settings-ux.md)). 절차는 [../ROADMAP.md](../ROADMAP.md) 맨 위.
