# 게임 모드 기획

현재 구현: **돌아가며 그리기(classic)**, **한 명이 그리기(fixed)**, **속도전(blitz)** — 2026-09-24 추가.
아래는 다음에 추가할 후보. 구현 난이도는 현재 구조(턴 순서 `turnOrder`, 단일 캔버스 `ops`, 채팅 정답 판정, 갤러리) 기준.

## 우선순위 높은 후보

### 1. 이어 그리기 (릴레이) — 난이도 ★★☆
- 한 단어를 여러 명이 **차례로 N초씩** 이어 그린다(예: 3명 × 15초). 그리는 사람도 단어를 알고, 나머지가 맞힌다.
- 재미 포인트: 앞사람이 그린 걸 살려야 해서 협동감이 크고, 짧은 시간이 긴장감을 준다.
- 구현: 한 턴 안에 "현재 붓을 든 사람"이 바뀌는 서브 타이머. `drawerId`를 턴 중간에 교체하고 `draw:*` 권한만 넘기면 된다. 점수는 맞힌 사람 + 릴레이 참가자 균등 분배.

### 2. 텔레스트레이션 (그림 → 글 → 그림) — 난이도 ★★★
- 첫 사람이 단어를 그리면, 다음 사람은 그림만 보고 **단어를 글로 적고**, 그다음 사람은 그 글만 보고 다시 그린다. 마지막에 원본 단어와 최종 그림을 나란히 공개.
- 재미 포인트: 전달 과정의 왜곡이 폭소 포인트. 이미 만든 **갤러리**(제시어·그림 나열, PNG 저장)와 궁합이 가장 좋다.
- 구현: 채팅 정답 판정 대신 "제출" 입력, 참가자마다 다른 화면(그리기/받아쓰기)이 동시에 진행되는 병렬 구조가 필요. 서버 상태 설계가 가장 큰 작업.

### 3. 속도전 (블리츠) — 난이도 ★☆☆
- 그리기 시간 20~30초, 힌트 없음, 단어 후보 1개(자동 선택), 라운드 많이. 맞힌 순서에 따라 점수 차등 폭을 크게.
- 재미 포인트: 대기 시간이 거의 없어 인원이 적을 때(2~3명) 특히 좋다.
- 구현: 사실상 **설정 프리셋** + 후보 자동 선택 옵션. 가장 빨리 추가 가능. 모드 카드로 노출하면 진입 장벽이 낮다.

### 4. 베스트 드로잉 (투표) — 난이도 ★★☆
- 모두가 **같은 단어를 동시에** 각자 그린다(60초). 끝나면 익명으로 나열하고 투표. 표를 많이 받은 그림이 점수.
- 재미 포인트: 정답 맞히기 실력과 무관하게 그림 실력/개그로 승부. 갤러리에 전원 그림이 남는다.
- 구현: 플레이어별 `ops` 저장(현재 단일 `ops`를 맵으로 확장), 투표 단계 추가. 채팅 정답 판정은 끈다.

## 그다음 후보

### 5. 팀전 — 난이도 ★★☆
- 두 팀으로 나누고, 출제자는 자기 팀만 맞힐 수 있게(상대 팀 채팅은 판정 안 함). 팀 점수 합산.
- 구현: 플레이어에 `team` 필드, 정답 판정에 팀 필터, 순위를 팀 단위로.

### 6. 스파이 (한 명은 단어를 모른다) — 난이도 ★★★
- 출제자 한 명을 빼고 **모두 단어를 안다**. 각자 짧게 한 획씩 이어 그리며, 스파이는 모르는 척 그려야 한다. 끝나면 스파이 지목 투표.
- 재미 포인트: 마피아류 심리전. 4명 이상에서 재미.
- 구현: 릴레이(1번) 위에 투표 단계를 얹는 형태.

### 7. 핸디캡 변형 (설정 토글로) — 난이도 ★☆☆
- 한 획 모드(붓을 떼면 끝), 지우개 금지, 색 1개만, 좌우 반전 캔버스, 시간이 갈수록 캔버스가 안개로 가려지는 "안개 모드" 등.
- 구현: 대부분 클라이언트 툴바 제한 + 서버 검증 한두 줄. 별도 모드보다 **설정 패널의 토글**로 두는 편이 맞다.

### 8. 두 단어 / 문장 모드 — 난이도 ★☆☆
- "비 오는 날 우산 쓴 강아지"처럼 조합 제시어. 부분 정답에 부분 점수.
- 구현: 사전에 조합 생성 규칙 추가, 정답 판정을 토큰 단위 부분 일치로.

## 추천 순서
1. **속도전** — 프리셋 수준이라 바로 추가 가능, 소인원 방의 체감 개선.
2. **이어 그리기** — 지금 구조에서 자연스럽게 확장되고 협동 재미가 새롭다.
3. **베스트 드로잉** — 갤러리·PNG 저장 기능의 활용도를 크게 올린다.
4. **텔레스트레이션** — 가장 재미있지만 가장 큰 작업. 3번의 "플레이어별 캔버스"를 먼저 만들면 절반은 준비된다.
