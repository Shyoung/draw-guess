# 운영자 가이드 — 세션을 언제 어떻게 쓰나

작성 2026-09-30 · 세션은 **draw-guess 폴더에서** 연다(폴더 밖에서 열면 역할 이름·CLAUDE.md가 안 잡힌다). 운영자가 하는 일은 GO / STOP / 보류와 방향 조정, 그리고 세션 밖의 실제 행동(게시·DM·단톡)이다.

## 세션 다섯 가지
| 세션 | 언제 | 여는 법 | 모델 | 하는 일 |
|---|---|---|---|---|
| **사이클** | **매일 1회** (아침 등) | `/ops-cycle` | Sonnet | 답 반영 → 마케팅 일일 보고 · 제품 분류 · 승인된 개발(builder) → QA → 결함 수정 → 보드 갱신. 마지막에 "결정 필요"와 "오늘 운영자 할 일 3개"를 준다 |
| **기획** | 새 모드·기능 아이디어가 있을 때, 월 초 | `/product-session` | 목록 정리 Sonnet · 설계 Opus · 신규 모드 Fable | 대화로 아이디어를 뽑고 설계 문서를 쓴다. 승인(GO)한 설계는 BACKLOG로 쪼개져 사이클이 만든다 |
| **기능(큰 작업)** | 큰 기능·신규 모드를 하나 정했을 때, 며칠에 걸쳐 | `/feature <기능>` | Opus(신규 모드 초기 설계는 Fable). builder는 작음 Sonnet·중간 이상 Opus | 이 세션이 운영자와 직접 기획하고 설계 문서를 쓴 뒤 GO를 받아 feature 브랜치·전용 워크트리에서 쪼갠 항목을 한 번에 최대 3개 소화한다. 개발 중 피드백은 세션에서 바로 말하면 설계 문서 수정 → 구현 → 로컬 확인이 이어진다. 완성되면 develop에 머지해 스테이징으로 넘긴다 |
| **마케팅** | 게시 전후, 회고 날 | (필요 시 새 세션에서 "marketing-strategist 정의를 읽고 …") | Sonnet, 회고·제휴 문안은 Opus | 세션 밖 활동을 돕는다: 커뮤니티 글·DM 초안 다듬기, 스트리머 조사, 게시 후 반응 정리, 2주·월 회고 |
| **관리자** | 구조가 어긋났을 때만 | 홈 폴더 세션 또는 draw-guess 폴더 | Sonnet | 스킬·에이전트·규칙 수정. 매일 열 필요 없다 |

개발은 두 레인이다. **작은 항목**은 사이클 안의 builder가 BACKLOG "다음" 표를 위에서부터 소화한다. **큰 기능**은 기획 세션에서 설계 → 운영자 GO(ROADMAP "설계 승인") → 기능 세션이 feature 브랜치에서 며칠에 걸쳐 만들고, 완성되면 develop에 머지해 스테이징으로 넘긴다. 큰 기능은 동시에 하나만 진행하고 일상 사이클과 병행한다. 기능 개발 중에는 스테이징에 안 올라가므로 로컬에서 확인하고, 폰 실기기 확인은 머지 뒤에 한다. node_modules는 세션이 `npm ci`로 설치하니 운영자가 할 일이 없다.

## 하루 루틴
1. **사이클을 돌린다.** 끝나면 보드의 결정 필요에 "n번 GO / STOP / 보류"로 답한다.
2. **오늘 운영자 할 일 3개를 실행한다.** 게시, DM, 단톡, 확인 같은 세션 밖 행동이다.
3. 필요하면 게시 글 초안 다듬기는 마케팅 세션, 아이디어는 기획 세션을 연다.
4. GO를 준 결과를 바로 보고 싶으면(예: 머지 GO) 사이클을 한 번 더 돌려도 된다. 토큰은 두 배로 든다.

## 주기 일정
- **매주 월요일**: 사이클 보고에서 채널별 ref 표와 대역폭을 본다(성장 계획 7-3). 필요하면 기획 세션에서 이번 주 제품 항목을 정리한다.
- **2026-10-12(월) 2주 회고**: 마케팅 세션(Opus)으로 KPI 표 채우기 → 기획 세션으로 로드맵 월별 목표 숫자 확정, 신규 모드 후보 압축.
- **월말**: 마케팅 회고, 로드맵 갱신.
- **게시·방송 1시간 전부터는 main 머지 금지**(보드 예정 일정).

## 세션을 여러 개 열 때
메인 체크아웃은 사이클 전용이고, 기획·관리자·마케팅 세션은 자기 워크트리에서 문서만 고친다(CLAUDE.md "동시 작업 규칙"). 사이클이 도는 중에 다른 세션을 열어도 된다.

## 세션이 길어지면
구조와 상태는 전부 파일(BOARD·BACKLOG·TEST-LOG·ROADMAP·docs/product)에 있다. 세션은 며칠씩 이어 쓰지 않고 새로 열어도 잃는 게 없다. 대화 중 나온 아이디어는 세션을 닫기 전에 문서에 남겨 달라고 요청한다.
