## 알려진 한계
- 사이클은 사람이 하루 한 번 켠다(클라우드 예약 실행은 미검토).
- 문서용 워크트리에는 node_modules가 없어 테스트·서버 실행을 못 한다. 개발 세션의 feature 워크트리는 `npm ci`로 설치한다(junction으로 메인과 연결하면 워크트리 삭제 때 원본이 지워질 수 있어 쓰지 않는다).
- 테스트 포트가 고정이라 개발 세션과 사이클이 테스트를 동시에 돌리면 충돌한다. BACKLOG "테스트 포트 오프셋" 완료 전까지는 시간이 겹치지 않게 한다.
- feature 브랜치는 스테이징에 배포되지 않는다(무료 플랜 750시간 한도). 실기기 확인은 머지 뒤에 한다.
- 세션 간 대화는 없고 파일 기반 비동기다.
- 사이클의 서브에이전트 이름은 draw-guess 폴더에서 열린 세션에서만 잡힌다(아니면 범용 에이전트에 역할 파일을 읽히는 폴백).
